# 키워드 마스터 — 크롬 확장 (개인용)

배포된 `https://keyword-master-delta.vercel.app` 의 `/api/analyze` 를 그대로 호출하는 얇은 팝업 확장입니다.
서버 코드/비밀키는 그대로 두고, UI만 팝업으로 옮긴 것이라 별도 설정이 필요 없습니다.

## 설치 (압축해제된 확장 프로그램으로 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 `extension` 폴더 선택
4. 툴바에 아이콘이 생기면 클릭해서 키워드 입력 → 분석

이미 로드해 둔 상태에서 이 폴더 파일이 바뀌었다면(예: 이번 오버레이 기능 추가), `chrome://extensions` 카드의 **새로고침 아이콘**을 눌러야 반영됩니다.

## 기능

- 팝업에서 키워드 입력 → 검색량·경쟁강도 표 조회 (`/api/analyze`, 상위 50개)
- 최근 검색어 8개를 칩으로 저장 (`chrome.storage.local`)
- 아무 페이지에서나 텍스트 선택 → 우클릭 → **"OO 키워드 마스터로 분석"** → 팝업이 열리며 자동 분석
  - 크롬 127 미만이면 팝업이 자동으로 안 열릴 수 있어, 이 경우 툴바 아이콘에 배지(●)가 뜹니다. 아이콘을 클릭하면 대기 중인 키워드로 자동 분석됩니다.
- 우측 상단 "전체 화면 열기"로 언제든 원래 웹앱으로 이동 (순위 조회·태그 최적화 등 팝업에 없는 기능용)

### 검색 사이트 오버레이

아래 사이트에서 검색어가 있는 페이지(검색결과 화면)를 열면 우측 하단에 **"📊 키워드 분석" 플로팅 버튼**이 뜹니다.
페이지 로드 시 자동으로 API 를 부르지 않고, **버튼을 눌러야** 분석이 시작됩니다 (쿼터 절약).

| 사이트 | 감지 URL | 검색어 파라미터 |
|---|---|---|
| 네이버 통합검색 | `search.naver.com/search.naver` | `query` |
| 네이버쇼핑 | `search.shopping.naver.com`, `shopping.naver.com` | `query` |
| 쿠팡 | `www.coupang.com/np/search` | `q` |
| 지마켓 | `www.gmarket.co.kr/n/search` | `keyword` |
| 11번가 | `search.11st.co.kr/pc/total-search` | `kwd` |

버튼을 누르면 패널에:
- PC/모바일/합계 월간 검색량, 경쟁강도 등급
- 최근 검색 추이 미니 차트 (진행 중인 이번 달은 며칠치만 집계돼 값이 낮게 나오므로 제외하고 그립니다)
- 연관 키워드 TOP 8 을 검색량 비례 막대로 시각화

가 뜹니다. 데이터는 항상 네이버 소스 기준입니다 — 쿠팡·지마켓·11번가에서 검색해도 "이 키워드가 네이버에서는 어떤지"를 보여주는 것이지, 해당 쇼핑몰 자체 데이터가 아닙니다.

같은 키워드는 패널을 여닫아도 재호출하지 않고 캐시된 값을 씁니다 (탭을 새로고침하면 캐시도 초기화됩니다).

SPA에서 검색어만 바뀌어도 1초 이내에 새 검색어를 반영합니다. 패널이 닫혀 있으면 API를 호출하지 않으며, 조회 실패는 캐시하지 않아 다시 열면 재시도합니다.

> **11번가는 검색어를 이중 URL 인코딩해서 내려보냅니다.** (`kwd=` 값 자체가 `%25EA%25B2...` 처럼 한 번 더 인코딩된 채로 옴) `content.js` 의 `decodeExtra()` 가 이걸 감지해서 한 겹 더 벗겨냅니다. 다른 사이트 추가 시 패널 제목에 `%EA%B2%8C...` 처럼 인코딩된 문자열이 그대로 보이면 같은 문제이니 이 함수가 잡아줄지 먼저 확인하세요.

## 배포 도메인이 바뀌면

`popup.js`·`background.js`의 `API_BASE`, `content.js`의 `WEB_BASE`, `popup.html`의 전체 화면 링크, `manifest.json`의 `host_permissions`를 함께 바꿔야 합니다.

## 배포하지 않는 이유

개인 API 키(네이버 검색광고) 쿼터를 그대로 쓰는 구조라, 크롬 웹스토어에 공개하면 다른 사람들도 이 쿼터를 나눠 쓰게 됩니다.
공개하려면 사용자별 API 키를 입력받아 서버에서 서명하는 구조로 바꿔야 합니다 (README 본문 참고).
